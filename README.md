# Car Price Prediction using Machine Learning
Internship project — CodeAlpha Data Science Internship

## Objective
Predict the selling price of used cars based on features like present price, mileage, fuel type, transmission, and age.

## Dataset
Car Dekho Vehicle Dataset

## Approach
- Data cleaning (nulls/duplicates check)
- Feature engineering: converted Year to Car_Age, encoded categorical variables
- EDA: correlation heatmap, scatter plots
- Train/test split (80/20)
- Multiple Linear Regression

## Results
- R²: 0.8488707839193154
- MAE: 1.2163740193330352
- RMSE: 1.8658375680942374

## Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
